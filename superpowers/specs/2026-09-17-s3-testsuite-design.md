# S3: SBML test suite roundtrip harness

Date: 2026-09-17
Status: approved design, implementation pending

## Context

S1 built the package and the SBML to CellML converter, S2 the CellML to SBML
converter (both merged into `develop`). S3 measures both against the
semantic test cases of the SBML test suite and publishes the result: every
case is simulated with roadrunner (reference), converted to CellML and
simulated with libopencor, converted back to SBML and simulated with
roadrunner again; each simulation is compared with the expected results of
the suite using the tolerances of the case. The per-case status is committed
and rendered on the documentation site, and CI fails on regressions.

## Decisions

| Question | Decision |
|----------|----------|
| Suite source | `semantic_tests_v3.5.0.zip` from the GitHub release of `sbmlteam/sbml-test-suite`, downloaded on first use into `~/.cache/sbml2cellml/sbml-test-suite/3.5.0` (`SBML2CELLML_CACHE` overrides the cache root); version pinned in code; nothing vendored except three small fixture cases for the unit tests. |
| Case scope | Cases with an L3V2 file, `testType: TimeCourse`, and no component tag of an SBML package (`comp:`, `fbc:`, ...). Other cases are listed as skipped with the reason. |
| Gating and report | `testsuite/results.json` and `docs/testsuite.md` are generated by the harness and committed. A pytest test, enabled by `SBML2CELLML_TESTSUITE=1` (linux CI job, `tox -e testsuite`), reruns the suite and fails on any regression against the committed results and on a stale report. |
| Location | Subpackage `sbml2cellml.testsuite` with the command `sbml2cellml-testsuite`; optional extra `testsuite` (`libroadrunner`, `requests`, plus the `simulate` extra); `dev` includes it. |
| Process model | roadrunner and libopencor never share a process (they bundle different LLVM versions). Each runs in its own long-lived worker process with a per-call timeout; the main process does the conversions. |

## Section 1: layout and API

`src/sbml2cellml/testsuite/`:

- `cases.py`: `SUITE_VERSION = "3.5.0"`, `SUITE_URL` template, `CACHE_ENV = "SBML2CELLML_CACHE"`, `cache_dir() -> Path`, `ensure_suite(version=SUITE_VERSION, cache=None) -> Path` (returns the `semantic/` directory, downloads and unpacks once), `Settings` (frozen dataclass: `start`, `duration`, `steps`, `variables`, `absolute`, `relative`, `amount`, `concentration`, property `end`), `parse_settings(text) -> Settings`, `parse_model_info(text) -> dict[str, list[str]]` (the `key: values` lines of `NNNNN-model.m`), `Case` (frozen dataclass: `id`, `case_dir`, `sbml_path: Path | None` (L3V2), `settings`, `expected: pd.DataFrame`, `test_tags`, `component_tags`, `test_type`), `skip_reason(case) -> str | None`, `load_case(case_dir) -> Case`, `load_cases(root, ids=None) -> list[Case]`, `TestSuiteError`.
- `simulators.py`: functions executed inside a worker, importing their simulator lazily: `simulate_sbml(sbml: str, selections: list[str], start: float, end: float, steps: int) -> dict` (roadrunner, `{"columns": [...], "rows": [[...], ...]}`, `time` first), `simulate_cellml(cellml_path: str, start, end, steps) -> dict` (`sbml2cellml.simulate.run_timecourse`), `sleep(seconds)` (for the timeout tests).
- `worker.py`: `SimulatorWorker(name, timeout=60.0)` context manager: spawn-context process running `_serve(connection)`, `call(function, **kwargs) -> dict` sends `(function, kwargs)` and waits at most `timeout` seconds; on timeout or a dead process the worker is restarted and `SimulationTimeout` / `SimulationFailure` is raised; an exception inside the worker is returned as `{"error": "Type: message"}` and raised as `SimulationFailure`.
- `compare.py`: `compare(result: pd.DataFrame, expected: pd.DataFrame, settings) -> Comparison` (`VariableComparison(variable, max_error, max_excess, passed)`, `Comparison(variables, passed, message)`; a variable passes when `|a - e| <= absolute + relative * |e|` at every time point; missing variable, row count or time mismatch fail with a message), `species_quantities(model_sbml) -> dict[str, tuple[bool, str]]` (species id to `(has_only_substance_units, compartment id)`), `requested_frame(df, quantities, settings) -> pd.DataFrame` (the settings variables in the requested quantity: amount = concentration variable times the compartment column, concentration = amount divided by it), `strip_brackets(columns)`.
- `results.py`: `STAGES = ("reference", "sbml2cellml", "libopencor", "cellml2sbml", "roundtrip")`, `StageResult(status, message="", max_excess=None)` with `status` in `pass`, `fail`, `skip`; `CaseResult(id, test_tags, component_tags, stages)`; `SuiteResult(suite, version, cases, skipped)` with `to_json(path)`, `from_json(path)`, `counts(stage) -> dict[str, int]`; `regressions(old, new) -> list[str]`, `improvements(old, new) -> list[str]`. JSON is written with sorted keys and indentation, no timestamps.
- `runner.py`: `run_case(case, work_dir, roadrunner, libopencor, timeout) -> CaseResult`, `run_suite(cases, work_dir, timeout=60.0, progress=None) -> SuiteResult` (starts the two workers, runs the runnable cases, records the skipped ones).
- `report.py`: `render_report(result) -> str`, `write_report(result, path)`.
- `cli.py`: `main(argv) -> int` for `sbml2cellml-testsuite run|report`.

`sbml2cellml.simulate.run_timecourse` (S1) additionally returns the constants and computed constants of the libopencor task as constant columns, so every CellML variable, in particular the compartments, is a column.

`pyproject.toml`: extra `testsuite = ["sbml2cellml[simulate]", "libroadrunner>=2.10.0", "requests>=2.32"]`, `dev` uses `sbml2cellml[testsuite]` instead of listing `libroadrunner`; script `sbml2cellml-testsuite = "sbml2cellml.testsuite.cli:main"`; pytest marker `testsuite`.

## Section 2: pipeline

Per runnable case, in order; a stage records `pass`, `fail` (message: exception type and first line, or the comparison message; `max_excess` when compared) or `skip` (a required predecessor failed):

1. `reference`: roadrunner on the original L3V2 with `start`, `end = start + duration`, `steps`; selections are the settings variables, a species listed under `concentration` as `[id]`, everything else by id; brackets stripped from the result columns; compared with the expected results. Independent of the conversions: a failure here only says roadrunner cannot reproduce the case.
2. `sbml2cellml`: `convert_sbml2cellml(sbml_path, cellml_path, validate=True)`. Fail on any exception. `libopencor`, `cellml2sbml`, `roundtrip` skip.
3. `libopencor`: `simulate_cellml` of the CellML with the settings, `requested_frame` with the quantities of the original SBML, compared. Fail on exception or comparison.
4. `cellml2sbml`: `convert_cellml2sbml(cellml_path, sbml_path, validate=True)`. Fail on any exception; `roundtrip` skips.
5. `roundtrip`: `simulate_sbml` of the roundtrip SBML with the settings variables plus the compartment ids as selections, `requested_frame`, compared.

Every worker call has the timeout (default 60 s); a timeout is a `fail` with message `timeout`. Exceptions never abort the suite. The work directory holds `NNNNN.cellml` and `NNNNN-roundtrip.xml` per case for inspection.

Skipped cases (not runnable) are in `SuiteResult.skipped` with the reason: `no L3V2 file`, `test type <type>`, `package <prefix>`.

## Section 3: tests and gating

- `tests/data/testsuite/semantic/<id>/` holds three cases (`00001`, the first case with an `EventNoDelay` test tag, the first case with `FunctionDefinition` among the component tags), four files each (`-sbml-l3v2.xml`, `-settings.txt`, `-results.csv`, `-model.m`).
- `tests/test_testsuite_cases.py`: settings and model info parsing, `load_cases` on the fixtures, `skip_reason` for a copied case with a `comp:` tag, `ensure_suite` with a mocked download (a zip built in the test) and the cache directory from the environment variable.
- `tests/test_testsuite_compare.py`: pass, fail by tolerance, missing variable, time mismatch; `requested_frame` in both directions.
- `tests/test_testsuite_results.py`: JSON roundtrip, `regressions` and `improvements`, `counts`.
- `tests/test_testsuite_worker.py`: `simulate_sbml` through a worker for `00001`, `simulate_cellml` through a worker for `test_model.cellml`, the error path, the timeout with restart (`sleep`), both workers alive at the same time.
- `tests/test_testsuite_runner.py`: `run_suite` on the three fixtures: every stage has a status, `reference` and `sbml2cellml` pass for `00001`, files in the work directory, the JSON round-trips.
- `tests/test_testsuite_report.py`: the rendered markdown contains the summary counts, the failure reasons and the case rows; `cli` `report` writes the file; `cli run --cases 00001` on the fixture root.
- `tests/test_testsuite_full.py` (`@pytest.mark.testsuite`, skipped unless `SBML2CELLML_TESTSUITE=1`): downloads the suite, runs everything, asserts `regressions(committed, new) == []` and that the rendered report equals `docs/testsuite.md`; prints the improvements when there are any.
- `tox.ini`: `passenv` for `SBML2CELLML_TESTSUITE` and `SBML2CELLML_CACHE`; `[testenv:testsuite]` sets the variable and runs `pytest -n 0 -m testsuite`.
- CI: the ubuntu entry of the `test` matrix sets `SBML2CELLML_TESTSUITE=1` and caches `~/.cache/sbml2cellml` keyed by the suite version.

## Section 4: report and documentation

- `docs/testsuite.md` (generated, committed, "generated by sbml2cellml-testsuite, do not edit" comment): suite and package version, summary table per stage (pass, fail, skip, pass rate), "Failure reasons" per stage (message, count, up to ten case ids), "Skipped cases" (reason, count), "Cases" table (id, component tags, stage columns).
- `zensical.toml` nav "SBML test suite" after "Roadmap"; `docs/api/` pages for the testsuite modules; `docs/development.md` section on running the suite and accepting improvements; `docs/roadmap.md` item 2 done and the gaps linked to the report; `README.md`, `CLAUDE.md`, `release-notes/0.1.0.md`.

## Out of scope

- Fixing converter gaps revealed by the suite (S5).
- The stochastic and syntactic parts of the suite, SBML packages.
- Tuning simulator tolerances; libopencor and roadrunner run with their defaults.
