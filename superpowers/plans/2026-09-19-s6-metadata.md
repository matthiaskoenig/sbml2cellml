# S6: names, notes and annotations - Implementation Plan

**Goal:** the metadata of an SBML model survives the conversion to CellML in an RDF sidecar and comes back in the conversion to SBML (issue #44).

**Spec:** `superpowers/specs/2026-09-19-s6-metadata-design.md`

## Global Constraints

- Test first: every task starts with failing tests. Full annotations and google docstrings, ty without diagnostics, ruff clean, no em dash, no co-author trailer.
- roadrunner and libopencor never in one process; library code logs and never prints.
- Generated files only through their commands (`sbml2cellml-testsuite run`, `sbml2cellml-biomodels run`, `examples/repressilator_example.py --docs`).
- Branch `metadata-rdf`, one commit per task.

## Tasks

- [ ] **1 Rate variable for every reaction.** Tests: `simple_model` has the variable `r1`, the equations of S1 and S2 use `<ci>r1</ci>`, a reaction without kinetic law has none, stoichiometry and conversion factor tests still hold numerically (`tests/test_simulate.py`). Code: `reaction_ids` from `rates`, `_collect_reaction_terms` with `astnodes.name(rid)`, `_referenced_reactions` removed. Update the tests which count `<diff/>` or compare variable sets, the glimepiride structure test, `docs/index.md`, `CLAUDE.md`.
- [ ] **2 Ids.** Tests: every variable, the model and the units of a converted model have unique ids, a variable `units_x` next to units `x` does not collide, the model validates. Code: `_add_variable` sets the id, `CellMLUnits` sets `units_<name>` (through a callable for unique ids), the model id.
- [ ] **3 `metadata.py` writing.** Tests: `collect_metadata` and `write_metadata` for name, notes, SBO term, CV terms (nested), model history, level 2 dialect normalized, no record for an element without metadata, deterministic output. Code as in the spec.
- [ ] **4 `metadata.py` reading.** Tests: `read_metadata` returns the records written, subjects of another file are ignored, `apply_metadata` restores every property on a parameter, a unit definition and the model (history), the document validates.
- [ ] **5 Converters and CLI.** Tests: `convert_sbml2cellml` writes the sidecar, none without metadata or with `metadata=False`, stale sidecar removed; `convert_cellml2sbml` applies it (equivalence sets, units, model), `metadata=False` ignores it; `--no-metadata` of both commands; roundtrip of BIOMD0000000012.
- [ ] **6 Example and documentation.** Complete repressilator file, `--docs` writes `docs/roundtrip/repressilator.rdf`, fourth tab, example test compares it; docs pages, API page, conversion issues, `CLAUDE.md`.
- [ ] **7 Full runs.** `sbml2cellml-testsuite run` and `sbml2cellml-biomodels run`, review, commit the regenerated files; gating test, `tox run-parallel`, strict docs build.
- [ ] **8 Pull request, merge, patch release 0.4.1** per `docs/development.md`.
